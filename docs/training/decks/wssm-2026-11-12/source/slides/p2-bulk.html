Part 2 · Running a club net

Fast and furious? Bulk add

One box for every caller

Type callsigns as fast as they’re called

Ctrl+Enter adds them all

A typo doesn’t hold up the rest of the list

Fix it afterward

Click any row to edit it in place

When check-ins come in fast and furious, Bulk add keeps up. Type the callsigns as they’re called, with a semicolon between stations, and press Ctrl+Enter. Each one is added on its own, so a typo doesn’t hold up the rest. Anything you got wrong in the rush, click the row and fix it in place.
